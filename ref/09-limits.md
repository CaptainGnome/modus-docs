# Лимиты рантайма

Если это первый плагин — достаточно зелёного `dev`. Если нужны потолки — одна таблица.

**Правило.** Лимиты хоста стабильны в ABI 2; расхождение `dev` и Core по семантике (RAM vs sqlite) не отменяет цифры ниже для Core.

| Что | Потолок |
| --- | --- |
| WASM memory | 16 MiB |
| `init` | ~500 ms до trap (epoch) |
| HTTP | 15 s, 1 MiB, 4 inflight, 5 редиректов |
| WS | 2 сокета, кадры через `wait` |
| лог | 20/с |
| событие шины | 64 KiB |
| inbox `wait` | 64 |
| KV | 256 KiB / 256 ключей / 16 KiB значение / 60 set·delete/с |
| catalog | 256 KiB / 2048 эмоутов / 10 publish/с |
| settings.json | 32 KiB, 8 секций, 32 поля |
| `ui-slot.post` | 64 KiB, 10/с |
| `chat.act` | текст ≤ 500; ~10/с |

Следующая глава — [не в этом ABI](10-not-in-abi.md).
